# AI Plagiarism Detection System

## Опис проєкту

Десктопний застосунок для визначення текстової подібності документів та базового виявлення можливих запозичень.

Програма використовує метод TF-IDF для перетворення текстів у числові вектори та косинусну міру подібності для визначення рівня збігу між документами.

## Основний функціонал

- Ввід текстів вручну до 3 документів
- Завантаження `.txt` та `.docx` файлів
- Порівняння документів між собою
- Обчислення відсотка схожості
- Визначення рівня збігу:
  - низький
  - середній
  - високий
  - критичний / можливе запозичення
- Експорт результатів у `report.txt`
- Очищення всіх даних
- Модальні повідомлення при помилках
- Логування дій у `app.log`
- Налаштування програми через `config.json`
