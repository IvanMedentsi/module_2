# TF-IDF Text Similarity Analyzer (Electron App)

## 📌 Опис проєкту

Десктопний застосунок для аналізу та порівняння текстових документів із визначенням рівня їх схожості.
Побудований на базі Electron та використовує методи NLP (TF-IDF + Cosine Similarity).

---

## Основний функціонал

- Ввід текстів вручну (до 3 документів)
- Завантаження `.txt` файлів
- Порівняння документів між собою
- Обчислення відсотка схожості (TF-IDF + Cosine Similarity)
- Експорт результатів у `report.txt`
- Очищення всіх даних (Clear all)
- 🪟 Модальне повідомлення при помилках (менше 2 документів)

---

## Використані технології

- Electron.js
- Node.js
- JavaScript (ES6+)
- TF-IDF (natural library)
- Cosine Similarity
- HTML / CSS (UI)
