1 Цей проєкт є десктопним застосунком, розробленим на Electron.js, який дозволяє виконувати аналіз текстової подібності документів. Програма використовує алгоритм TF-IDF у поєднанні з косинусною мірою для визначення рівня схожості між введеними текстами. Користувач може вводити до трьох документів, отримувати результат у вигляді відсотків подібності та зберігати звіт у файл.
